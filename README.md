# AYRA Trading

Awaken Your Potential · Trade · Train · Evolve. Цифровая экосистема для трейдеров: журнал, рынок, квесты, персонаж, сообщество.

## Запуск
```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

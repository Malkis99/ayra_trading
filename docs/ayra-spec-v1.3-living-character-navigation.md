## 1. Living Character («живой трейдер»)

### 1.1 Идея
Каждое значимое действие пользователя в AYRA оставляет след на персонаже: опыт, характеристики, предметы, визуальные эффекты, записи в хронике. Пользователь видит, как его реальная жизнь превращается в историю персонажа.

### 1.2 Принцип «только вперёд» ⚠ [C]
- Пропуск дня не ухудшает вид персонажа, не «убивает» его настроение и не вызывает вину. В неактивные дни персонаж **отдыхает** (нейтральное состояние) и **ждёт**.
- Тело и пропорции не меняются от тренировок или питания: это риск нездорового отношения к телу, особенно для 16–17 лет. Прогресс показывается через **ауру, экипировку, анимации, титулы, окружение**.
- Никаких манипулятивных паттернов («твой персонаж грустит без тебя»).

### 1.3 Как действия отражаются на персонаже

| Действие пользователя | Эффект на персонажа |
|---|---|
| Выполнил квест | XP, рост характеристики, запись в хронику, шанс награды |
| Заполнил журнал / сделал пост-сессию | Discipline/Psychology, значок «журнал сегодня», эффект на карточке |
| Соблюдал риск и план | Эффект «Focus» на сессию, прогресс Process Score |
| Изучил урок Academy | Knowledge, открытие навыка, предмет «ученика» |
| Тренировка/прогулка | Strength/Endurance, эффект энергии, анимация |
| Weekly Review завершён | Недельная глава в хронике, награда недели |
| Серия дней | Рамка/эффект серии, титул |
| Помощь в сообществе (оценённая) | Social-значок, предметы сообщества |
| Level-up | Анимация, новая ячейка/навык, запись |
| Долгий перерыв | Состояние «Rest», приветственное возвращение (без упрёков) |

### 1.4 Состояние персонажа (Character State)
Вычисляется из последних событий: **Focus** (сессия/анализ), **Training** (физ/учёба), **Reflecting** (рефлексия), **Resting** (отдых, пауза), **On a Streak**, **Celebrating** (level-up/достижение). Влияет на: короткую анимацию, фон-эффект, подпись под персонажем. Не влияет на XP и рейтинг.

### 1.5 Хроника жизни (Chronicle)
Единая лента событий персонажа: уровни, квесты, значимые сессии, главы недель, предметы, достижения, гильдии. Фильтры по периодам и категориям. Приватна по умолчанию; пользователь может сделать публичными отдельные записи.

### 1.6 База (Home Base) 💡
Личное пространство персонажа (комната/штаб) в оригинальном стиле: витрина достижений, трофеи, рамки, питомец/компаньон, предметы коллекций. Обновляется по мере прогресса. Фаза позже (2D-сцена в MVP: фон + витрина).

### 1.7 Присутствие в продукте
- Аватар-чип в шапке всегда виден (клик → Character Hub).
- Home показывает персонажа + состояние + XP-полоску + ближайшие квесты.
- Реакции на события (маленькие анимации/всплывашки) — только на значимых моментах, отключаются настройкой «меньше движения» и в Focus Mode.
- Telegram: тот же персонаж и состояние в Mini App и в уведомлениях бота.

### 1.8 Приватность
Публичный профиль показывает только то, что выбрал пользователь: персонаж, уровень, бейджи, выбранные записи. Подробности журнала, здоровье, цели и заметки не публикуются автоматически.

## 2. Wardrobe и кастомизация (MMORPG-стиль)

### 2.1 Что можно надевать и менять
| Категория | Примеры |
|---|---|
| Внешность | Лицо, причёска, цвет кожи/глаз, тип телосложения (редактор), как в D-26 |
| Одежда | Головной убор, верх, низ, обувь, верхняя одежда, перчатки, очки/маски, украшения |
| Спина/плечи | Плащ, рюкзак, крылья-эффекты |
| Аура/эффекты | Эффекты вокруг персонажа (Focus, Streak) |
| Компаньон | Питомец/дрон/символ |
| Профиль | **Рамка аватара**, **фон профиля**, **баннер**, титул, nameplate (стиль ника) |
| Реакции | Позы, эмоции, анимации приветствия |
| Интерфейс | Темы карточек, значки, стиль индикаторов (только косметика) |

### 2.2 Редкость и наборы
Редкость: 5 ступеней с оригинальными названиями. Наборы (sets) дают косметический бонус-эффект при полном комплекте (например, особая аура), без влияния на XP, рейтинг, репутацию.

### 2.3 Источники предметов
Квесты · достижения · уровни · сезоны · недельные испытания · гильдии · кейсы за Coins · магазин за Coins · партнёрские награды (позже, 18+). Предметы привязаны к аккаунту (soulbound) в E1–E2 (Spec v1.2).

### 2.4 Правила
1. Только косметика: ни один предмет не влияет на XP, шансы, рейтинг, репутацию, доступ.
2. Предпросмотр «примерить» до использования/покупки.
3. **Лоадауты:** сохранённые комплекты (например, «Сессия», «Сообщество»).
4. Совместимость слоёв: предмет объявляет слоты, которые он занимает, и конфликтует с другими; порядок отрисовки z-order задан в спецификации ассетов.
5. Подходит для разных типов тела; нейтральные по полу варианты.
6. Ограничения на 16–17: контент соответствует возрасту; нет откровенных предметов; ограниченные партнёрские предметы.
7. Все названия и описания предметов — i18n (RU/EN).

### 2.5 Рендер и производительность
- Аватар собирается из слоёв (2D) и **кэшируется как готовое изображение** для ленты и списков; пересборка только при смене лоадаута.
- Лёгкие форматы (WebP/SVG), несколько размеров (чип, карточка, полный).
- Рамки/фоны подгружаются отдельно, не пересобирая персонажа.

### 2.6 Данные
Сущности: Item (шаблон), ItemInstance (экземпляр у пользователя), Slot, Loadout, Outfit, Frame, Background, Banner, Title, Collection, Source (откуда получен). Инвентарь меняется только через журнал операций (Spec v1.2, ledger).

### 2.7 Производство ассетов ⚠
- Нужен единый стиль-гайд (палитра, силуэты, освещение, размеры, якоря слоёв), иначе предметы не сочетаются.
- Ассеты можно создавать с помощью ИИ-генерации + ручная проверка и доработка; условия использования генераторов, авторские права и единый стиль `проверить`.
- Старт с небольшого каталога: ядро (по 3–5 предметов на слот, 3 рамки, 3 фона) для MVP, затем сезонные наборы.
- Ориентир стиля (inZOI/GTA) остаётся северным ориентиром, реализация поэтапная (Pack v1.0, 6.3).

## 3. Интерфейс и навигация (приоритет №1)

### 3.1 Принципы
1. **Любое ключевое действие ≤ 3 нажатий** от Home (добавить сделку — 1).
2. Одна главная задача на экран, одна главная кнопка.
3. Одинаковая структура навигации везде (web, Telegram, мобильный).
4. Пользователь всегда знает, где он (подсвеченный раздел, хлебные крошки, заголовок).
5. Новичок не видит сложное сразу: расширенные функции раскрываются по мере использования (progressive disclosure).
6. Быстрые пути для опытных: командная палитра, горячие клавиши.
7. Минимум шума, предсказуемое поведение, чёткие состояния (пусто / загрузка / ошибка / успех).

### 3.2 Основная навигация
**Web (боковое меню, сворачиваемое):**
1. **Home** (Today)
2. **Journal**
3. **Market**
4. **Quests**
5. **Community**
6. **Academy**
Внизу: **Settings**, **Help**.
Сверху: поиск / командная палитра, кнопка **«+ Добавить»**, уведомления, **аватар-чип** (вход в Character Hub и переключатели режимов Focus/Game).

**Mobile и Telegram (нижняя панель, 5 пунктов):** Home · Journal · Market · Quests · **Character**; Community и Academy в «Ещё» или вкладкой над главной. `проверить на тестах`

### 3.3 Карта разделов

| Раздел | Внутренние вкладки |
|---|---|
| Home | Today (квесты, события дня, персонаж), настраиваемые виджеты |
| Journal | Dashboard · Trades · Reports · Trading Plan · Strategies · Accounts · Notes |
| Market | Overview · Calendar · Macro · News · Scanner · Watchlist |
| Quests | Today · Week · Goals · Discipline Tracker · History |
| Community | Feed · Explore (v2) · Guilds · Arena · Мой профиль |
| Academy | Курсы · Бэктесты · Прогресс |
| Character Hub | Обзор · Wardrobe · Достижения · Хроника · Навыки · Профиль |
| Settings | Профиль · Аккаунты и вход · Приватность · Язык и тема · Уведомления · Тариф |

### 3.4 Быстрые пути
- Кнопка **«+ Добавить»** везде: сделка, заметка, запись настроения/эмоции, пост, событие.
- **Командная палитра** (Ctrl/Cmd+K): переход, действия, поиск по сделкам/заметкам/пользователям.
- **Закреплённые разделы** и последние открытые.
- Глобальный поиск с группами результатов.

### 3.5 Главная (Today)
Один экран «что делать сейчас»: приветствие + персонаж и состояние; 3 задания дня; события календаря на ближайшие часы; ключевые карточки рынка; кнопка «Добавить сделку»; прогресс недели. Остальное — настраиваемые виджеты (Pack v1.0, 14).

### 3.6 Состояния и обучение интерфейсу
- Пустые состояния с действием («Добавь первую сделку»).
- Короткие подсказки при первом открытии каждого раздела (можно отключить), без длинных туров.
- Единые паттерны для форм: автосохранение черновика, понятные ошибки, отмена действия (undo) для обратимых изменений.

### 3.7 Проверка удобства
- Список ключевых задач: добавить сделку, найти событие, отметить квест, изменить лоадаут, найти профиль, настроить уведомление.
- Замеры: время выполнения и ошибки; тест на 5 людях с прототипом до реализации.
- Приёмка каждого среза включает чек-лист навигации.

### 3.8 Доступность и скорость
- Контраст, клавиатура, размеры касаний, не опираться только на цвет.
- Цель по скорости: основные экраны открываются быстро, тяжёлые данные подгружаются постепенно со скелетонами (конкретные пороги задаст тест на прототипе).

## 4. Подготовка: что делаем

### 4.1 Weekend 0 (для тебя, без кода и без рискованных действий)
1. **Бренд:** проверить домен (AYRA и варианты) и поиск похожих торговых марок в нужных странах. Покупку домена — после моего списка вариантов и твоего подтверждения.
2. **Аккаунты (бесплатные тарифы):** GitHub (приватный репозиторий `ayra`), Supabase, Vercel. Регион БД выберем вместе.
3. **Telegram:** создать бота через @BotFather (имя и username); токен хранить только у себя, в чат и репозиторий не отправлять.
4. **Инструмент ИИ-разработки:** выбрать среду, где ИИ пишет код в репозитории (например, Claude Code или Cursor).
5. **Референсы:** 3–5 игр/сайтов, чей интерфейс и стиль персонажа тебе нравятся (скриншоты).
6. **Документы:** сохранить Pack v1.0 и Spec v1.1–v1.3 в папку `docs/` репозитория.
7. **Секреты:** пароли, ключи, токены — только в переменных окружения, не в чате и не в коде.
Все шаги обратимы; финансовых обязательств нет, кроме возможной покупки домена.

### 4.2 Что готовлю я
1. **Wireframes** главных экранов: Awakening, Home/Today, Journal (Dashboard, Trades), Market Overview, Character Hub + Wardrobe, Community профиль.
2. **Стиль-гайд интерфейса:** палитра, типографика, компоненты, состояния, иконки.
3. **Схема БД и права доступа** (User, AuthIdentity, Profile, Character, Item/Inventory, Trade, Account, Quest, Ledger и др.).
4. **Стартовый каталог квестов** (черновик ~50 шаблонов RU/EN) и каталог целей/привычек для онбординга.
5. **Файл правил для ИИ-разработчика:** структура проекта, стиль кода, словарь терминов, запреты (например, нет необратимых действий без подтверждения).
6. **Чек-листы приёмки** срезов S0–S2.
7. **Стиль-гайд ассетов персонажа** (слои, размеры, якоря, палитра, правила совместимости).

# WATCH-1A — компактный список наблюдения

## Границы

Один основной список AYRA: название, тикер, категория, переход к существующему графику, добавление, удаление и перестановка. Поиск применяется только к добавленным инструментам; фильтр включает все шесть категорий каталога, включая акции.

Приоритеты не добавлены ни в локальное хранилище, ни в облако. Их синхронизация относится к WATCH-1B. Сценарии WATCH-2 не реализованы. Цены и проценты не рассчитываются приложением.

## Сохранение и порядок

Формат `version: 1, ids, updatedAt`, лимит 30, существующие cloud codec, mergeMarket и синхронизация не меняются. Поиск и категория — временное состояние представления; они не записывают список и не меняют timestamp.

Явная перестановка меняет местами соседние **видимые** инструменты в каноническом массиве. Например, `[EURUSD, BTC, GBPUSD]` с фильтром Forex превращается в `[GBPUSD, BTC, EURUSD]`: скрытый BTC сохраняет индекс. Границы определяются видимым списком. Добавление идёт в конец. Удаление не пишет в Chart Notes и настройки графика.

Перед пользовательской мутацией читается текущий список существующего пространства хранения, чтобы не применять устаревшую копию после облачного обновления. Существующая модель разрешения конфликтов всего списка сохраняется; поэлементное слияние не вводится.

## TradingView

Котировки перенесены ниже списка в закрытый по умолчанию нативный details. Скрипт и iframe загружаются после раскрытия и удаляются при закрытии. Повторное раскрытие инициирует загрузку заново. Фильтры AYRA не меняют набор котировок и не перезагружают открытый iframe. Явное изменение списка обновляет его конфигурацию.

Высота области ограничена 320 px, длинный список прокручивается внутри. На узких экранах широкая таблица TradingView имеет собственную горизонтальную прокрутку, а страница не расширяется. Существующие источник, уведомление о задержке, timeout и retry переиспользуются без изменения общего виджета. Появление iframe не является подтверждением свежести рыночных цен.

## Доступность

Поиск имеет подпись, категории используют существующий Select, раскрытие — нативный summary. Кнопки строк имеют доступные имена и область 44×44 px. Перестановка сохраняет фокус на действии или инструменте при достижении границы; удаление переводит его на соседний видимый инструмент, поиск либо Add для пустого списка. Esc закрывает каталог добавления и возвращает фокус. Изменения объявляются через live region; переведённые строки не хранятся в состоянии.

## Проверки и снимки

`watchlist-view.test.ts` проверяет поиск, все категории, неизменность списка и перестановку со скрытыми позициями. `market-watchlist-compact.spec.ts` покрывает RU/EN на 360/390/768/1024/1440 px, 30 инструментов, фильтры, клавиатуру, reload, график, заметки/интервал, lazy quotes, отказ и задержку TradingView. Существующие проверки облачной синхронизации остаются обязательными.

Снимки до/после находятся в `docs/screens/watch-1a`. Используется одинаковый набор семи инструментов. TradingView заменён детерминированной тестовой iframe без вымышленных котировок. Старые снимки сняты на исходной сборке до изменений.

Локальные результаты:

- `npx tsc --noEmit` — PASS.
- `npm run lint` — PASS; прежние предупреждения Login/Journal без изменений.
- `npx vitest run lib/market/watchlist-view.test.ts lib/market/watchlist.test.ts` — 12 PASS.
- `npx playwright test -c playwright.supabase.config.ts e2e-supabase/market-watchlist-compact.spec.ts e2e-supabase/market-sync-status.spec.ts e2e-supabase/market-sync-two-devices.spec.ts` — 20 PASS, включая новую production-сборку локального приложения и изолированный fake Supabase.
- `npx playwright test -c work/watch1-market.config.ts` — 20 PASS: существующий `e2e/market-chart.spec.ts`, Chromium и WebKit, отдельная mock-auth сборка. `work` — локальная переносимая обёртка для Windows, не часть PR; GitHub CI запускает исходную конфигурацию Linux.

Падений тестов в этих запусках не было. Исходные снимки: четыре PASS до правок на 390/1440 px в RU/EN. Пример высоты одинаковой панели: desktop EN 814.5 → 606.5 px, mobile RU 866.5 → 768.25 px. Сравнение включает закрытые второстепенные котировки после редизайна и старый всегда видимый контейнер до него.

Ограничения: доступность внешнего TradingView и актуальность его цен не гарантируются приложением. Браузерные тесты используют заглушку поставщика, проверяя конфигурацию, отказ, timeout и retry. Облачная модель по-прежнему разрешает конфликты целого списка; облачные приоритеты потребуют отдельного WATCH-1B. Production, SQL, API, источники и feature flags не менялись.

# CPI США — доступ к первоначальному выпуску BLS

## Что подтверждено

- Датированный релиз за октябрь 2026 опубликован 10 ноября в 08:30 по Нью-Йорку. В Table 1 общий CPI составляет +0,4% м/м SA, базовый +0,3% м/м SA. Оба изменения г/г NSA отсутствуют, поскольку BLS не собирало необходимую базу за октябрь 2025. [Архив BLS](https://www.bls.gov/news.release/archives/cpi_11102026.htm) · [Расписание BLS](https://www.bls.gov/schedule/news_release/cpi.htm)
- В production-журнале market_feed_runs пять записей bls-cpi-check за 12–16 ноября содержат HTTP 403 на этот точный URL и items=0. Последняя попытка зафиксирована 16 ноября в 06:50:11 UTC. Это ошибка доступа до разбора таблицы. Код использует Vercel Function с maxDuration=60, а HTTP-запрос архива ограничен 15 секундами на заголовки и тело. Запрос production-функции вручную не запускался.
- Прямой запрос из среды разработки на тот же URL вернул 403 за 988 мс. Заголовки Content-Type: text/html и Server: AkamaiGHost, Location и Retry-After отсутствовали. Эти заголовки относятся к локальному запросу. Журнал production сохранил статус и URL без исходных заголовков, а время предыдущих попыток вне доступного окна Vercel runtime logs.
- Сервер ответил на правильный URL, однако правило, по которому BLS отказал в доступе, неизвестно. География, IP и правила CDN остаются гипотезами. Ответ 403 и локальный заголовок Server не устанавливают причину решения на стороне BLS.

API подтвердил уровни октября 2026: CUSR0000SA0 337,476; CUUR0000SA0 337,511; CUSR0000SA0L1E 339,900; CUUR0000SA0L1E 339,921. Для октября 2025 все четыре ряда вернули пропуск. CPI м/м использует CUSR и SA, CPI г/г использует CUUR и NSA. Производственные факты сохраняют series, period, unit, adjustment, release_url, source_updated и vintage=release. Сезонные индексы могут пересматриваться за пять лет, поэтому из уровней API не реконструируются первоначальные темпы. ## Поведение сборщика

Оба существующих пути CPI делают один GET к датированному архиву с ручной обработкой редиректов. Неуспешный HTTP-ответ записывает статус и признаки HTML, Location и Retry-After без содержимого тела и значения Location. Неожиданный тип ответа и неподтверждённые дата, период или таблица относятся к invalid. 403 по-прежнему считается blocked и ставит паузу на сутки через существующий RPC. Для 429 сохранён существующий учёт Retry-After. Таймаут и сетевой сбой оставляют факт неподтверждённым.

Для автоматического появления значений штатный сборщик должен получить датированный HTML напрямую из Vercel, подтвердить дату и период, разобрать допустимую Table 1 и успешно сохранить результат в существующую строку через RPC. После 403 окно проверки открывается по истечении паузы, пока выпуск входит в существующий семидневный горизонт. Для выпусков за пределами этого горизонта потребуется отдельно согласовать штатный способ восстановления. Октябрьские значения г/г могут получить только подтверждённое состояние «Не опубликовано» из исходного релиза.

Доступная официальная замена с подтверждённой версией выпуска из Vercel пока не установлена. Состояние недоступности сохраняется до подтверждения источника. Ограничения BLS соблюдаются, дополнительные запросы и новые источники в production не добавлены.

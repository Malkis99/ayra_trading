# Очередь задач для Jules (по одной задаче на один PR)

Правило: следующая задача только после merge предыдущей. Каждая задача заканчивается чек-листом приёмки для владельца.

---
## T0. Проверка каркаса
**Цель:** убедиться, что проект собирается, исправить конфигурацию.
- `npm install`, `npx tsc --noEmit`, `npm run build`, `npm run dev`.
- Исправить найденные ошибки конфигурации (Tailwind, TS, ESLint). Добавить `.env.example` (пустой, с комментарием), `.prettierrc`, скрипт `npm run typecheck`.
- Проверить, что CI (`.github/workflows/ci.yml`) проходит.
**Приёмка:** главная страница с логотипом AYRA открывается, сборка проходит.

## T1. Оболочка приложения (Shell)
**Цель:** навигация и общий каркас (см. раздел "Fixed UX decisions" в JULES_PROMPT.md и прототип).
- Layout: боковое меню (Home, Journal, Market, Quests, Community, Academy), **карточка профиля над Settings/Help**, верхняя панель, нижняя навигация на мобильном.
- "+ Добавить": модальное окно по центру всей страницы с плитками (Сделка, Заметка, Эмоция, Пост, Событие), закрытие по клику вне окна и Esc, фокус-ловушка, слой выше всего.
- Чип плана (Free) рядом с колокольчиком → `/plans`.
- Переключатель Focus/Game, поиск (пока заглушка), уведомления (заглушка).
- Страницы-заглушки: `/journal`, `/market`, `/quests`, `/community`, `/academy` с вкладками из docs (Pack v1.0, разделы 7, 8, 10) и пустыми состояниями.
- Компонент Starfield (canvas) только на Home и Profile; отключается при `prefers-reduced-motion` и в Focus mode; пауза при скрытой вкладке; не более ~70 частиц.
- Основная область скроллится внутри (`min-h-0`), боковая панель не растёт и не обрезается.
**Приёмка:** на 360px и 1440px; открывается/закрывается модальное окно; нет горизонтального скролла во вкладках; карточка профиля и Settings/Help всегда видны.

## T2. Локализация RU/EN
**Цель:** словарь переводов с самого начала.
- Простой провайдер словарей `ru`/`en` (без префиксов в URL), переключатель языка в Settings, сохранение в cookie/localStorage.
- Вынести все строки T1 в словари. Форматирование дат и чисел по локали.
**Приёмка:** переключение языка меняет весь интерфейс без перезагрузки.

## T3. Состояние игры и Home
**Цель:** локальное (пока без сервера) состояние и полноценная страница Home.
- Store (React context + localStorage с обработкой ошибок): профиль, уровень, XP, Coins, квесты дня, экипировка, достижения, хроника, ежедневная награда, план (Free/Pro/Elite).
- Правила из прототипа: 40 XP за квест, формула `need(lv) = 80 + lv*40`, лимит награды раз в день.
- Home (по списку в JULES_PROMPT.md). Рынки и календарь — демо-данные с пометкой "демо".
- Страница `/plans`: сравнение Free/Pro/Elite, выбор плана (демо, без оплаты). Цены — placeholders.
**Приёмка:** квест выполняется, XP растёт, level-up показывается, награда забирается один раз в день, данные сохраняются после перезагрузки.

## T4. Профиль и персонаж
**Цель:** страница `/profile` по прототипу.
- Сцена персонажа: SVG-фигура, 10 слотов (граненая форма, цвет по редкости), перетаскивание для поворота на 360° (pointer events, есть вид сзади), кнопки "Сброс", "360°" (автоповорот), "Фон сцены" (3 варианта), пьедестал с кольцами.
- Вкладки: Обзор (ник, уровень, титул, репутация, XP/Coins, подписчики/подписки, оформление: рамка/фон/титул, задания, характеристики), Wardrobe (фильтр по слотам, предпросмотр, "Надеть", "Снять слот", лоадауты "Сессия"/"Сообщество", блокировка по уровню), Достижения, Хроника, Посты (локальные, с дисклеймером), Статистика.
- Редактирование ника и "о себе" (модальное окно по центру).
- Карточка профиля в сайдбаре синхронизирована с профилем.
**Приёмка:** предметы меняют вид персонажа, предпросмотр не сохраняется без "Надеть", вращение работает мышью и пальцем, все вкладки открываются без полос прокрутки.

## T5. Character Awakening (регистрация/онбординг)
**Цель:** 5 шагов по Pack v1.0 раздел 5 и v1.3.
- Один вопрос на экран, "Назад"/"Пропустить", сохранение черновика, обязательно только: ник, язык, возраст (16–17 / 18–24 / 25–34 / 35+), опыт, рынки, главная проблема.
- Генерация стартовой программы по правилам (таблица 1.3 в v1.3/Pack v1.0): квесты, путь (Structure/Discipline/Mind/Analysis), с пометкой "Почему я это получил".
- Финальное сообщение: «Система пробуждения завершена. Твой путь начинается сегодня».
**Приёмка:** онбординг проходится за ~3 минуты, пропущенные вопросы становятся side-квестами.

## T6. Journal v1 (локально)
- Счета, ручной ввод сделки, таблица, Dashboard (KPI в R/$/%; по умолчанию R), календарь дней, Notes, Trading Plan, Strategies (теги), статусы достоверности (Unverified).
- Process Score сделки (чек-лист), журнал "не вошёл".
**Приёмка:** добавление сделки обновляет Dashboard и календарь.

## T7. Backend: Supabase и единый аккаунт
**Требуется владелец:** создать проект Supabase и выдать значения через переменные окружения (не в чат и не в код).
- Схема БД и RLS: User, AuthIdentity (email/google/telegram), Profile, Character, Inventory, Trades, Accounts, Quests, Ledger (append-only), AuditLog.
- Вход email-код/magic link и Google; привязка Telegram (валидация `initData`, одноразовая ссылка привязки); сценарии 3.2 из Pack v1.0; слияние аккаунтов — только с подтверждением владельца.
- Перенос состояния из localStorage в БД. Награды начисляет только сервер (идемпотентно, с дневными лимитами).
**Приёмка:** один аккаунт видит те же данные в вебе и в Telegram Mini App (после T9).

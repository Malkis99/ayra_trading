# Core PCE, июль 2026 — проверка BEA 26-39

Read-only проверка 19 ноября 2026. В предыдущем production-отчёте AYRA я ошибочно отнёс значение 0,0 к Core PCE. Проверенные HTML и PDF этого не подтверждают.

- HTML выпуска — https://www.bea.gov/news/2026/personal-income-and-outlays-july-2026
- PDF того же выпуска — https://www.bea.gov/sites/default/files/2026-08/pi0726.pdf
- Идентификатор — BEA 26-39, 26 августа 2026, 08:30 EDT / 12:30 UTC. Отчётный месяц — июль 2026.
- Текст HTML и страница 2 PDF сообщают рост Core PCE price index на 0,2% к предыдущему месяцу.
- Таблица «Personal Income and Related Measures», «Percent change from preceding month», страница 3 PDF: строка «PCE price index excluding food and energy», колонка July — 0,2; колонка June — 0,1.
- В той же таблице строка «Real PCE», колонка July — 0,0; колонка June — 0,4. Это реальный объём потребительских расходов, отдельный показатель.
- HTML содержит точные ячейки `<td>Real PCE</td> ... <td>0.0</td>` и `<td>PCE price index excluding food and energy</td> ... <td>0.2</td>` (стили и вложенные span опущены).

Текущие источники согласованы по Core PCE. Исторический HTML-снимок, доказывающий прежнее противоречие, отсутствует. Из этой проверки нельзя заключить, что BEA исправляло страницу. Значение +0,2% соответствует проверенному датированному выпуску; production-данные при проверке не изменялись.

Эта история представляет значения отдельных первоначальных выпусков, а не последний пересмотренный ряд одной версии. После annual update от 30 сентября исторические значения в интерактивных таблицах могут отличаться. Для сравнения исходного июля следует использовать датированный выпуск BEA 26-39, а не текущую Table 2.8.7.

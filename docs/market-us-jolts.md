# JOLTS: официальное расписание и первоначальные значения

База main после #153 — e80ec74. Сохраняются код us_jolts, важность 2 и существующие ID. Серия JTS000000000000000JOL соответствует Total Nonfarm Job Openings, SA. Точное значение из тысяч отображается в миллионах с тремя знаками.

## Расписание и бюджет запросов

Суточный сборщик читает [официальную таблицу](https://www.bls.gov/schedule/news_release/jolts.htm) одним GET. Повторный последовательный запуск в тот же UTC-день ограничен существующим журналом запусков. Используются явные период, дата и время с переводом America/New_York в UTC. Список прежних дат используется для первоначального заполнения. Дальнейшие даты поступают из опубликованных строк BLS.

Период и стадия образуют стабильный ключ для RPC 0012. Перенос принимается при сравнимой официальной версии. Исчезновение строки, 403, 429, тайм-аут и исчерпанный горизонт сохраняют существующие строки. HTML-таблица не даёт надёжного сигнала отмены. При конфликте без версии прежнее событие сохраняется и появляется запись в диагностике.

Архивные факты делят прежний интервал BLS с CPI, PPI и API для NFP. В каждом таком проходе допускается одна загрузка. JOLTS исключён из запроса текущего BLS API, включая previous и пересмотры. Дополнительных запросов для previous нет.

## Факты и история

[Архив сентября](https://www.bls.gov/news.release/archives/jolts_11032026.htm) подтверждает 7.523M и пересмотренный август 7.190M. [Первоначальная публикация августа](https://www.bls.gov/news.release/archives/jolts_09292026.htm) подтверждает 7.079M. Парсер проверяет заголовок релиза, дату, период, Table 1, строку Total, уровни в тысячах, SA и пометку preliminary. В result_meta сохраняются период, серия, время и URL публикации, а также происхождение previous. При отсутствии числа в релизе используется только однозначно подтверждённый initial предыдущего месяца из БД либо передаётся NULL.

RPC 0012 оставляет прежний previous при входящем NULL. Если на старом событии значение было заполнено заранее, оно может остаться без подтверждённого release-provenance. Исторические actual и metadata сохраняются. Суточный bls-jolts-history отмечает неподтверждённые значения в пределах текущего окна чтения истории. Конфликт RPC series units or period changed фиксируется без обхода защиты.

## Стадии проверки

| Стадия | Доказательство |
| --- | --- |
| Адаптер и сборщик | Нормализованные HTML-фрагменты официальных публикаций, проверка исторических данных и контролируемых ошибок |
| Доступ из сервера | При аудите прямой Node GET к расписанию, ICS и архивам получил 403 Access Denied. Доступ из Vercel не подтверждён. Чтение runtime-логов вернуло отдельный 403 Forbidden |
| Сохранение в БД | Локальная PGlite с существующей RPC 0012 проверяет ID, повторную запись и защиту старой истории |
| Отображение | Playwright читает данные из fake Supabase и проверяет факты в существующем календаре на 360 и 1440 px |

Fixtures отражают опубликованные значения. Исходный HTTP-ответ сервера не был получен. Если BLS продолжит отказывать в доступе, новые месяцы будут зависеть от восстановления разрешённого доступа. Доступность BLS из Vercel, запись через реальную загрузку и результат на рабочем сайте требуют отдельного подтверждения.

Итог команд TypeScript, lint, build, unit, миграций и обоих e2e-наборов приведён в Draft PR.

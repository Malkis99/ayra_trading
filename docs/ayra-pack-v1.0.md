## 1. Vision и принципы

Большинство платформ отвечает «сколько я заработал?». AYRA отвечает: **«кем я становлюсь благодаря своему пути?»**

Петля: Trade → Analyze → Learn → Improve → Evolve → Repeat.

Принципы:
1. Процесс важнее результата; XP за качество действий, не за прибыль.
2. Игровой уровень ≠ торговая статистика ≠ отметки обучения.
3. AYRA не даёт сигналов и финансовых рекомендаций; помогает замечать события и принимать решения самому.
4. Честность о достоверности данных.
5. Один аккаунт на любой платформе.
6. Минимум шума, тёмный интерфейс, оригинальный визуальный язык.

Не делаем: сигналы, гарантии дохода, управление деньгами, блокчейн/токен на первом этапе, копирование сделок.

## 3. Единый аккаунт

**Модель.** `User` владеет всеми данными. `AuthIdentity` (email, google, telegram) привязываются к User; identity принадлежит одному User; ключ Telegram — неизменяемый `telegram_id`. Сервер — источник правды.

| Сценарий | Поведение |
|---|---|
| Новый через Web | User + identity; предложение привязать Telegram |
| Новый через Telegram | Валидация `initData` → User + identity; предложение добавить email/Google |
| Есть веб-аккаунт, первый вход через Telegram | Mini App спрашивает «Войти в существующий / Создать новый»; вход по коду на email или одноразовому коду из веба; Telegram привязывается, данные те же |
| Привязка из веба | Одноразовая ссылка на бота (`start=link_<token>`), токен живёт минуты |
| Два отдельных аккаунта | Merge: доказательство владения обоими, выбор основного, дедупликация сделок, суммирование XP с пересчётом по правилам, снапшот и окно отката |
| Отвязка | Нельзя убрать последний способ входа |

Безопасность: никакого авто-слияния по совпадению email; подпись `initData` проверяется на сервере; сессии по устройствам; уведомления о привязке/отвязке. Google OAuth внутри Telegram WebView может не работать → вход по коду/magic link. `проверить`

## 5. Character Awakening

**Правила:** обязательная часть до ~3 минут; один вопрос на экран; «Назад» и «Пропустить»; прогресс сохраняется; пропущенное становится side-квестами профиля с XP.

| Шаг | Содержание | Обязательно |
|---|---|---|
| 1 Персонаж | Ник, аватар, стиль, язык, часовой пояс (авто), возраст (16–17 / 18–24 / 25–34 / 35+) | Ник, язык, возраст |
| 2 Образ жизни | Увлечения, спорт, чтение, языки, навыки, время на развитие (мультивыбор + свой вариант) | Нет |
| 3 Торговый профиль | Опыт, рынки, стиль, стратегия, журнал, главная проблема, время на анализ | Опыт, рынки, проблема |
| 4 Цели | Цель в трейдинге, причина прихода, навыки за 3 месяца, образ через год, что мешает, что будет успехом | Нет |
| 5 Программа | Квесты, навыки, миссии, цели недели, материалы | Автоматически |

Финал: «Система пробуждения завершена. Твой путь начинается сегодня».

**Правила программы (rule-based, с пометкой «Почему я это получил»):** нет журнала → квест «Запиши сделку»; проблема дисциплина/эмоции → вес Discipline/Psychology; нет стратегии → путь «Построй систему»; мало времени → короткие квесты; интерес к спорту → квесты Body по виду активности.

**Стартовый путь:** Structure / Discipline / Mind / Analysis — не ярлык и не рейтинг, меняется со временем.

Приватность: свободные тексты видны только владельцу; для 16–17 финансовые вопросы упрощены; согласие на AI-анализ отдельным необязательным чекбоксом.

## 6. Профиль, персонаж, квесты

### 6.1 Характеристики
Discipline, Trading, Intelligence, Focus, Psychology, Knowledge, Endurance, Strength. Уровни, XP, навыки, дерево, достижения, титулы.

### 6.2 Daily Quests и трекер дисциплины (в профиле)
- Категории: Trading, Discipline, Body, Mind (+Psychology, Learning, Social, Lifestyle).
- Поля: сложность, длительность, награда, характеристика, способ подтверждения.
- Трекер дисциплины: ежедневный чек-лист + паттерн-тепловая карта (как идея в TradeTrack), связан с XP.
- Дни восстановления, недельные испытания.

### 6.3 Персонаж (⚠ D-20/D-26)
Видение: персонаж с полноценным редактором лица и тела (уровень inZOI/GTA). Реальность: 3D-редактор такого класса — отдельный большой проект (арт, морф-таргеты, рендер, оптимизация), при разработке только ИИ, по выходным и почти без бюджета.
Поэтапно:
- **A (MVP):** 2D-модульный аватар — слои (тело, лицо, причёска, одежда, аксессуары, цвета), ползунки и пресеты; стиль полуреалистичный/стилизованный.
- **B:** 3D-превью с параметрическим лицом/телом (лицензированный avatar SDK или собственный пайплайн glTF + morph targets) `проверить варианты и условия`.
- **C:** полноценный редактор и анимации, если проект докажет ценность и появится бюджет.
Северный ориентир — стиль и свобода кастомизации inZOI/GTA; MVP не блокируется 3D.

## 7. Journal

Разделы: **Dashboard · Trades · Reports · Trading Plan · Strategies · Accounts · Notes**.

### 7.1 Dashboard
KPI-карточки (P&L, profit factor, winrate, avg win/loss), последние сделки, кривая эквити, календарь дней, Process Score недели. Переключатель **R / $ / %** (по умолчанию R, выбор запоминается).

### 7.2 Trades
Таблица и карточка сделки: инструмент, направление, время, цены, SL/TP, объём, комиссии, результат, сетап (стратегия), сессия, теги, эмоции до/во время/после, причина входа, ошибка, оценка исполнения, скриншоты (с разметкой), заметка. Статус достоверности: Unverified / Imported / Connected / Verified.

### 7.3 Reports
Winrate, R-multiple, expectancy, profit factor, drawdown, серии; разрезы по сетапу, инструменту, сессии, часу, дню недели, эмоции, ошибке; фильтр по статусу достоверности.

### 7.4 Strategies (Playbook)
Правила, чек-лист, условия, кастомные поля/теги под любой стиль (в том числе SMC/ICT как пользовательские теги).

### 7.5 Trading Plan
План на день/неделю: Daily Bias, ключевые уровни, события, лимиты риска, чек-лист перед сессией.

### 7.6 Accounts
Несколько счетов: личный, проп-челлендж, демо. **Prop Rules Tracker:** дневной лимит убытка, максимальная просадка, цель, мин. дни; индикатор «осталось до лимита».

### 7.7 Notes (новое, D-08)
Свободные заметки трейдера: быстрые заметки, привязка к сделке/дню/инструменту/стратегии, теги, поиск, закрепление, шаблоны (пост-сессия, ошибка недели), вложения-скриншоты. Заметки приватны.

### 7.8 Улучшения сверх TradeTrack 💡
Process Score и матрица Process × Outcome; журнал «не вошёл»; pre-trade чек-лист; разметка скриншотов; связь сделок с календарём новостей (для Trade DNA); безопасный шаринг в R/% без сумм.

### 7.9 Импорт
- MVP: загрузка отчёта MT5 (HTML/CSV), мастер сопоставления, предпросмотр, дедупликация, отчёт о результате.
- Далее: cTrader (официальный Open API `проверить`), Match-Trader `проверить доступность API`, автоподключение MT5 через стороннего провайдера `проверить условия, цену и приватность`; уровни Connected/Verified строятся на этом.
- Пользователь 16–17: только ручной ввод и демо-импорт (15.3).

## 8. Market Center

Единый раздел: **Overview · Calendar · Macro · News · Scanner · Watchlist**. Цель: за 2 минуты понять, что сегодня важно для моих инструментов.

### 8.1 Market Overview
- Ядро: **DXY, S&P 500, Nasdaq, Gold, Oil, BTC**; пользователь добавляет карточки из каталога (Dow, DAX, EUR/USD, US10Y и др. доступны, не показаны по умолчанию).
- Карточка: цена, изменение за день, недельная динамика, ключевые уровни (из заметок пользователя), рыночный статус (открыт/закрыт/пре-маркет).
- Каталог инструментов: FX, индексы, металлы, энергия, акции-лидеры, топ крипто; приоритеты наполнения по данным.

### 8.2 Economic Calendar
События: CPI, PCE, NFP, FOMC, ставки, GDP, PMI, речи ЦБ, занятость и др. Фильтры по стране/валюте/важности/моим инструментам; напоминания; история прогноз/факт; часовой пояс пользователя. **Объяснение влияния:** библиотека по основным событиям + AI-комментарий по текущему значению (Pro/Elite). Заметки до/после события, связь с журналом.

### 8.3 Macro
Ставки и заседания ЦБ, инфляция/занятость/ВВП/PMI по странам (карточки трендов), доходности и кривая, DXY, сырьё. «Режим рынка» простыми словами с источниками и временем обновления (Pro/Elite).

### 8.4 News Intelligence (Pro/Elite)
Карточка новости: заголовок, источник, время, ссылка. AI-разбор в 4 блоках: **Что произошло · Почему важно · На что обратить внимание · Что может изменить сценарий**. Факты и интерпретация ИИ визуально разделены; указана уверенность. Полный текст статей не воспроизводится. Источники: официальные публикации (ЦБ, статистические службы) и публичные RSS; платные ленты — позже.

### 8.5 Данные (⚠ реальное время vs нулевой бюджет)
Реальные котировки по FX/индексам/металлам/энергии лицензируются и стоят денег, особенно для показа пользователям. Поэтапно:
- **Этап 1 (бесплатно):** встроенные виджеты TradingView для графиков/Overview/календаря (условия использования, атрибуция, задержки по некоторым биржам `проверить`) + собственные котировки крипто в реальном времени через публичные биржевые потоки.
- **Этап 2 (после дохода Pro/Elite):** платный провайдер реального времени для остальных рынков; выбор по цене, лицензии на показ и надёжности `проверить`.
- Scanner начинает с инструментов с реальным временем (крипто), затем расширяется.

### 8.6 Trading Setup Scanner (Pro/Elite)
- Правила пользователя: цена у отмеченного POI/уровня; подход к предыдущему high/low дня; изменение волатильности (ATR); простые технические условия; предстоящее событие; комбинации.
- Каналы: Telegram, web push, email; лимиты правил по тарифам.
- Уведомление нейтральное («условие приблизилось»), без «купи/продай». Распознавание паттернов — позже.
- Серверный воркер, антиспам (повтор не чаще заданного интервала), журнал срабатываний.

## 11. Gamification

- XP за качество: план выполнен, анализ, обучение, тренировка, журнал заполнен, риск соблюдён, квест выполнен.
- Дневной cap XP, кулдауны, уникальность действий.
- Уровни подтверждения: Self → Evidence → Cross-check (данные импорта) → Peer.
- Детектор аномалий, правила видны пользователю.
- Нет наград за размер сделки, плечо, количество сделок, абсолютный P&L; нарушение собственных лимитов блокирует бонусы дня.
- XP за сессию начисляется после неё (Session Flow), не во время сделки.

## 12. Economy, кейсы, партнёры

- **Валюта (Coins):** только зарабатывается (квесты, достижения, серии, челленджи); не продаётся за реальные деньги, не выводится, не переводится.
- **Кейсы (D-07):** покупаются за Coins; публичные шансы; дневной лимит и пауза после серии; гарантия редкого предмета после N открытий; призы — косметика, титулы, рамки, ограниченные бусты без влияния на рейтинг; история открытий и возможность отключить кейсы. Юридическая проверка локальных правил по лутбоксам `проверить`.
- **Партнёрские награды (будущее):** скидки/перки проп-фирм. Рекомендация ⚠: давать детерминированно за достижения (например, серия журнала + Process Score выше порога), в случайных кейсах — только малые скидки; партнёры помечены, условия видны; не влияют на рейтинг/Academy; AI не рекомендует конкретные фирмы; 18+ и не для режима 16–17. Требует договоров.

## 14. UX/UI

- Тёмная тема по умолчанию, графитовые поверхности, сдержанные фиолетовый (действия) и золотой (достижения, редкое) акценты; светлая тема позже.
- Минимум шума, анимации только для XP, level-up, квестов, кейсов, переходов; режим «меньше движения».
- Быстрый доступ к журналу и рынкам; кнопка «+ Сделка» везде; командная палитра (Ctrl/Cmd+K); хоткеи.

## 15. Технологии, процесс разработки, приватность

### 15.1 Предлагаемый стек (D-22, выбор Claude) `проверить актуальные условия при старте`
| Слой | Выбор | Почему |
|---|---|---|
| Frontend | Next.js + TypeScript, Tailwind, shadcn/ui, next-intl | Один код для web и Mini App, хорошо знаком ИИ |
| Backend/DB | Supabase (Postgres, Auth, Storage, Realtime, RLS) | Управляемый сервис, бесплатный старт, меньше администрирования |
| Авторизация | Supabase Auth + свой вход через Telegram (валидация `initData`, выпуск сессии) + таблица AuthIdentity | Единый аккаунт |
| Воркеры | Небольшой Node-сервис (потоки котировок, Scanner, уведомления) на дешёвом хостинге | Нужны постоянные соединения |
| Задачи по расписанию | Cron (генерация квестов, Weekly Review, синк календаря) | — |
| AI | Внешний LLM API, квоты на пользователя, кэш, структурированные ответы; только Pro/Elite | Контроль стоимости |
| Уведомления | Telegram-бот, web push, email-провайдер | Требование Scanner |
| Графики | Виджеты TradingView + Lightweight Charts для собственных | Бесплатно, быстро |
| Мониторинг | Журнал ошибок (Sentry-класс), логи, резервные копии БД | Надёжность |

### 15.2 Процесс «код пишет ИИ» (D-21)
- Репозиторий в Git, ветки, история изменений; окружения dev/staging/prod.
- Работа маленькими вертикальными срезами (один срез ≈ один рабочий выходной).
- Автотесты на критичную логику: XP/анти-накрутка, импорт и дедупликация, merge аккаунтов, права доступа.
- Версионированные миграции БД; резервные копии; секреты не в коде.
- Правило: **необратимые действия (удаление данных, миграции на проде, merge) выполняются только после твоего подтверждения.**
- Этот Pack + файл правил для ИИ (стиль кода, структура, словарь терминов) — постоянный контекст.
- Ты не пишешь код, но принимаешь результат по чек-листам приёмки (я готовлю их к каждому срезу).

### 15.3 Приватность, безопасность, 16+
- Минимизация данных, согласия, приватность по умолчанию, экспорт/удаление, очистка EXIF, шифрование, права доступа на уровне строк (RLS), rate limiting, проверка загрузок, не хранить пароли брокеров.
- AI не использует данные одного пользователя для другого; данные не идут на обучение без отдельного согласия.
- **16+ (D-05):** ⚠ журнал показывает P&L и связан с брокерскими счетами, а брокеры обычно требуют 18+. Поэтому режим 16–17 (D-24): ручной ввод и демо, без Connected/Verified, без кейсов с партнёрскими призами, без партнёрских предложений, без платных подписок без разрешения, ограниченные личные сообщения. Правила возрастного согласия различаются по странам (например, GDPR) `проверить`.
- Дисклеймеры: не финансовая рекомендация; торговля несёт риск потери капитала; игровые показатели не отражают реальные результаты.
- Модерация: жалобы, блокировки, фильтр скама, запрет гарантий дохода.

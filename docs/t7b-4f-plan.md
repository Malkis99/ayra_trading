Поэтому у сделки, пришедшей с другого устройства, будет видно «Скриншот хранится на другом устройстве» вместо пустого места.
3. **Проверочный SQL** `supabase/checks/cloud_sync_owner.sql` (только чтение): включён ли флаг и сколько записей у аккаунта в каждой таблице журнала.

## 2. Что важно знать до включения (ограничения)

- **Синхронизируется только Журнал:** счета, сделки, стратегии, «Не вошёл», планы, заметки, история импорта, основной проп-счёт.
- **Не синхронизируются** (будут позже, отдельными шагами):
  - **скриншоты сделок** — остаются на устройстве, где их добавили (0005);
  - **XP, монеты, уровень, задания, достижения, персонаж и профиль** — на каждом устройстве свои, как сейчас (0006 / 0007). На телефоне уровень может отличаться от компьютера — это ожидаемо.
- **Гостевые данные** в аккаунт сами не переносятся (правило уже действует).
- **Изменения с другого устройства приходят:** при открытии приложения, при возврате на вкладку, при появлении сети и в фоне раз в 5 минут. Мгновенно не приходят.

## 3. Команды SQL (выполняешь ты в Supabase → SQL Editor)

Вместо `ТВОЯ_ПОЧТА` подставь почту, с которой входишь в AYRA. В репозиторий почта не записывается.

**3.1 Проверка до включения** (только чтение):

```sql
SELECT u.id, u.email, f.cloud_sync, f.updated_at
FROM auth.users u
LEFT JOIN public.user_features f ON f.user_id = u.id
WHERE u.email = 'ТВОЯ_ПОЧТА';
```

Ожидается одна строка: `cloud_sync` пустой (`NULL`) или `false`.

**3.2 Включить только у тебя:**

```sql
INSERT INTO public.user_features (user_id, cloud_sync)
SELECT id, TRUE FROM auth.users WHERE email = 'ТВОЯ_ПОЧТА'
ON CONFLICT (user_id) DO UPDATE SET cloud_sync = TRUE;
```

Ожидается `INSERT 0 1`. Повторить запрос 3.1 — `cloud_sync = true`.

**3.3 Проверить, что больше ни у кого не включено:**

```sql
SELECT count(*) AS accounts_with_sync FROM public.user_features WHERE cloud_sync;
```

Ожидается `1`.

**3.4 Сколько записей твоего журнала в облаке** (после загрузки) — файл `supabase/checks/cloud_sync_owner.sql` из PR 4f: число строк по каждой таблице, удалённые отдельно.

**3.5 Откат — выключить синхронизацию:**

```sql
UPDATE public.user_features SET cloud_sync = FALSE
WHERE user_id = (SELECT id FROM auth.users WHERE email = 'ТВОЯ_ПОЧТА');
```

- Сервер сразу перестаёт принимать запись в облако.
- Приложение перестаёт обращаться к облаку в течение 5 минут (столько оно помнит ответ о флаге) или сразу после перезагрузки страницы.
- **Ничего не удаляется**: журнал на устройствах остаётся как есть, облачные записи тоже. Значок облака исчезает, Журнал работает локально, как до T7b.
- Удалять облачные записи без отдельного решения **не нужно**. Если когда-нибудь понадобится — я подготовлю отдельный запрос, и выполнишь его только ты.

## 5. Чек-лист ручной проверки (два твоих устройства: компьютер и телефон)

Каждый пункт: что сделать → что должно быть.

**Компьютер (первое устройство)**
1. Обнови страницу Журнала → в шапке значок «Журнал ещё не в облаке» (облако со стрелкой). В Журнале кнопка «Загрузить в облако».
2. Нажми кнопку → цифры совпадают с журналом (счета, сделки, заметки…). Нажми «Скачать копию (JSON)» → файл скачался.
3. «Загрузить» → прогресс → «Готово: журнал в облаке» → значок «Сохранено в облаке» (облако с галочкой). Кнопка пропала.
4. Запрос 3.4 → число сделок в облаке = число сделок в журнале.

**Телефон (второе устройство)**

5. Войди тем же аккаунтом:
   - журнал на телефоне был пустой → сам появился журнал с компьютера и одно уведомление «Журнал загружен из облака»;
   - на телефоне был свой журнал → значок «Журнал ещё не в облаке» → «Загрузить в облако» → окно показывает «Только здесь / Только в облаке / Отличаются» → «Загрузить» → на телефоне всё, отличающееся — через диалог выбора.
6. Шапка на телефоне: все значки помещаются, аватар целиком; панель значка открывается во всю ширину.

**Обмен**

7. Добавь сделку на компьютере → на телефоне вернись в приложение (или подожди до 5 минут) → сделка появилась.
8. Измени сделку на телефоне → на компьютере появилась правка.
9. **Без сети:** на телефоне режим полёта → добавь сделку → значок «Нет сети», в панели «Ждёт отправки: 1» → выключи режим полёта → значок «Сохранено» → сделка появилась на компьютере.
10. **Конфликт:** на телефоне режим полёта → измени сделку X (например, заметку). На компьютере измени ту же сделку X по-другому. Выключи режим полёта, открой Журнал на телефоне → диалог «Запись изменена на двух устройствах», обе версии рядом, отличие подсвечено → выбери вариант → через минуту на обоих устройствах одинаково.
11. **Удаление против правки:** как пункт 10, но на компьютере удали сделку → на телефоне «На другом устройстве эту сделку удалили, а здесь изменили» → выбери «Взять из облака» → сделки нет на обоих.
12. «Решить позже» → диалог закрылся, значок «Нужен выбор: 1» → нажми значок → «Решить конфликт» → диалог открылся на этой же странице.

**Выход, другой аккаунт, импорт**

13. На телефоне режим полёта → добавь сделку → Настройки → «Выйти и удалить данные аккаунта с этого устройства» → окно «Не всё сохранено в облаке: 1 изменение» → «Отмена». Выключи режим полёта → снова → «Подождать отправки» → обычное подтверждение → **отмени** (данные не удаляем).
14. Выйди и войди другим (тестовым) аккаунтом на компьютере → значка облака нет, твоих сделок нет. Вернись в свой аккаунт → всё на месте.
15. Импортируй файл TradeTrack на компьютере → на телефоне появились те же сделки; XP за импорт не начислен.
16. Сделка со скриншотом, добавленная на компьютере → на телефоне подпись «Скриншот хранится на другом устройстве».

## 6. Риски и что делать

| Что заметил | Что делать |
|---|---|
| Пропали записи на устройстве | Откат 3.5. Восстановление — из резервной копии JSON (импорт). Прислать мне время и скриншот панели значка |
| Задвоились сделки | Не откатывать сразу: прислать мне. Скорее всего, одни и те же сделки были введены на двух устройствах вручную (их id разные) — об этом предупреждает окно загрузки |
| Значок «Не удалось синхронизировать» долго не проходит | Нажать «Повторить»; если не помогло — прислать текст панели |

| На телефоне другой уровень / XP | Ожидаемо: прогресс пока не синхронизируется (раздел 2) |

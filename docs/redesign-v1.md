# AYRA — Redesign v1 (план)

Цель: спокойный, современный интерфейс с ясной иерархией. Меньше рамок, теней и одновременно видимых блоков; та же функциональность.

Скриншоты «до»: `docs/redesign/screens/before/` (360px и 1440px, все страницы). «После» снимаются тем же скриптом в `docs/redesign/screens/after/`:
```
CI=true AYRA_E2E_AUTH_MOCK=1 npm run build && npx next start -p 3000   # в отдельном окне
node scripts/screenshots.mjs docs/redesign/screens/after
```

## 1. Что не так сейчас (по скриншотам «до»)

**Везде**
- Каждый блок — карточка с рамкой, градиентом и внутренней тенью; карточки вложены в карточки. Визуальный шум, нет главного акцента.
- Заголовки блоков (`.h4`) мелкие и серые (12px, `text-mu`) — слабая иерархия. Размеры текста скачут: 10, 11, 12, 13, 14px в одном блоке.
- Отступы непоследовательные: `p-2.5`, `p-3`, `p-3.5`, `p-4`, `gap-1.5…gap-5` без системы.
- Несколько первичных кнопок на одном экране (Home: «Добавить» в шапке, «Добавить сделку», «Забрать награду», «Записать сделку»).
- Золото используется для чипа плана и монет — по правилам оно только для достижений и редких предметов.
- Цвета и тени задаются ad-hoc (`#1c1b28`, `from-[#211f2b]`, `bg-[#50348f22]`), в Shell есть несуществующие классы `violet-glow`.
- Мобильный: кнопки и чипы ниже 44px (табы, «День 1…7», чипы шапки), шапка перегружена (поиск, «Добавить», монеты, план, колокольчик, аватар).

**Home** — 13 блоков подряд (баннер гостя, приветствие с 3 чипами и 3 кнопками, задания, план на сегодня, награда, журнал, персонаж, рынки, календарь, тема дня, сообщество, ИИ-бриф, хроника). На 360px — экран прокрутки длиной ~2700px. Дубли: XP/уровень/монеты в приветствии, в карточке персонажа, в сайдбаре и в шапке; «Добавить сделку» трижды.
**Journal** — 7 табов + фильтры из 4 нативных `select` с белым фоном (не в стиле), календарь и недельные итоги видны даже без сделок; KPI с пустыми `0.00 R` до первой сделки.
**Quests** — у каждого задания два вида кнопок-иконок без подписей и постоянный блок «Почему я это получил» — высокая плотность.
**Profile** — «Обзор» перегружен: подписчики, репутация, XP и 8 характеристик одновременно; сцена и панель разной высоты.
**Market / Community / Academy** — заглушки: заголовок, табы и пустая пунктирная коробка с технической фразой («Вкладка: Обзор», «(T8)»).
**Settings** — 5 карточек одинакового веса, кнопка «Пройти знакомство» продублирована как заголовок и как кнопка; английские фразы («Local Only», «total quota», «Warning»).
**Plans / Login / Awakening** — в целом аккуратно; Login внутри полного Shell с сайдбаром и шапкой (отвлекает от одного действия).

## 2. Принципы

1. **Один акцент на экран.** Одна первичная кнопка (filled violet) на экран; остальное — secondary/ghost.
2. **3–5 крупных блоков.** Всё остальное — в табах, свёрнутых секциях («Ещё») или на своей странице. Ничего не удаляем: только переносим.
3. **Воздух вместо рамок.** Секции разделяются отступами и заголовками; рамка — только у интерактивных или сгруппированных элементов. Без вложенных карточек и внутренних теней.
4. **Единая сетка и набор компонентов:** `Card`, `Button`, `Chip`, `Tabs`, `Modal`, `EmptyState`, `SectionHeader` в `components/ui/`.
5. **Понятные пустые состояния:** иконка, одна фраза, одно действие. Без технических меток (T8, «Вкладка: …»).
6. **Быстрые действия под рукой:** «+ Сделка» и «Задания на сегодня» доступны с Home и из шапки.
7. **Мобильный:** нижняя навигация, тап-зоны ≥44px, без горизонтальной прокрутки, табы скроллятся без полосы.
8. **Доступность:** видимый фокус, контраст текста ≥4.5:1, `prefers-reduced-motion` отключает анимации.

## 3. Токены

Цвета (CSS-переменные в `globals.css`, Tailwind читает их):

| Токен | Значение | Назначение |
|---|---|---|
| `--bg` / `ink` | `#121117` | фон приложения |
| `--surface-1` / `s1` | `#18171f` | карточки |
| `--surface-2` / `s2` | `#201f29` | поля, вложенные элементы, hover |
| `--line` / `line` | `#2c2a38` | границы |
| `--text` / `tx` | `#ebe9f3` | основной текст |
| `--muted` / `mu` | `#a09eb2` | вторичный текст (контраст ~7:1 на `ink`) |
| `--primary` / `pri` | `#50348f` | первичные кнопки, активная навигация |
| `--accent` / `vi` | `#a38ad1` | ссылки, фокус, прогресс |
| `--gold` / `go` | `#d6a94a` | **только** достижения и редкие предметы |
| `--danger` | `#e58a8a` | опасные действия, ошибки |
| `--success` | `#6fcf97` | рост, успех |

Радиусы: `sm 8px` (чипы, поля), `md 12px` (кнопки, элементы списков), `lg 16px` (карточки), `full` (аватары, бейджи).

Отступы: шаг 4px. Внутри карточки — 16px (мобильный) / 20px (≥md); между блоками — 16px / 24px; между секциями страницы — 32px.

Типографика (Manrope, заголовки страниц и имена — serif):

| Роль | Размер / вес |
|---|---|
| Заголовок страницы | serif 24px (моб.) / 30px, 700 |
| Заголовок секции | 15px, 600, `tx` |
| Основной текст | 14px, 400 |
| Вторичный текст | 13px, 400, `mu` |
| Подписи, бейджи | 12px, 500 |

Минимум 12px; размеры 9–11px убираем.

Тени: только у плавающих слоёв (модалки, меню) — `0 12px 32px #00000066`. У карточек теней нет.

Анимации: 150–200ms на hover/focus; анимации со смыслом (level-up, награда) сохраняются, под `motion-safe`.

## 4. Компоненты (`components/ui/`)

- `Card` — `surface-1`, радиус `lg`, рамка `line`, без градиента и тени; вариант `quiet` (без рамки) для секций.
- `Button` — `primary` (один на экран), `secondary` (рамка), `ghost` (текст), `danger`; размеры `md` 44px, `sm` 36px (только на десктопе).
- `Chip` — нейтральный, `accent`, `gold` (только редкое/достижения).
- `Tabs` — подчёркивание, тап-зона 44px, горизонтальный скролл без полосы, `role="tablist"`.
- `Modal` — центр экрана, фокус-ловушка, Esc, слой выше всего (на базе существующих модалок).
- `EmptyState` — иконка, заголовок, одна фраза, одно действие.
- `SectionHeader` — заголовок секции + необязательная ссылка/действие справа.

Старые классы (`.card`, `.btn`, `.btn-ghost`, `.chip`, `.tabs`) на время миграции переписываются на новые токены, чтобы не ломать непереведённые страницы.

## 5. Страницы: что убираем из основного вида и куда

| Страница | Главный акцент | Основной вид (≤5 блоков) | Переносим |
|---|---|---|---|
| Shell | навигация | сайдбар: 6 пунктов + карточка профиля + Настройки/Помощь; шапка: поиск, «+ Добавить», план, колокольчик | Фокус/Игра → меню профиля и Настройки; монеты → карточка профиля |
| Home | «Задания на сегодня» | приветствие с прогрессом уровня; задания дня; «План на сегодня»; рынок кратко; «Ещё» | награда → в блок заданий; журнал/персонаж/календарь/тема дня/сообщество/ИИ-бриф/хроника → свёрнутая секция «Ещё»; дубли XP/монет убираем |
| Journal | «+ Сделка» | табы (Дашборд, Сделки, План, Ещё ▾); фильтры одной строкой; пустое состояние | Отчёты, Стратегии, Счета, Заметки → «Ещё ▾»; календарь и недельные итоги — только при наличии сделок |
| Quests | «Выполнить» у первого задания | сводка дня; основные задания; бонусные свёрнуты | «Почему я это получил» → раскрывается по нажатию; иконки замены/пропуска → меню «⋯» с подписями |
| Profile | персонаж | сцена + Обзор (имя, уровень, репутация, XP) | подписчики и 8 характеристик → таб «Статистика» |
| Market / Community / Academy | — | заголовок, табы, `EmptyState` без технических меток | — |
| Settings | — | группы: Аккаунт и данные устройства; Знакомство; Интерфейс; Хранилище | «Диагностика» → свёрнута внизу; английские строки → словари |
| Plans | выбор плана | без изменений структуры, новые токены | — |
| Login / Awakening | одно действие | фокус-экран без сайдбара и шапки | — |

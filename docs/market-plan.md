## 3. Данные

### 3.1 Что реально можно бесплатно

| Категория | Показать бесплатно | Свои свечи для Replay и бэктеста |
|---|---|---|
| **Крипта** | Виджеты; свои котировки из публичных данных бирж (Binance и др.) без ключа | **Да:** публичные свечи бирж. Условия Binance для показа на коммерческом сайте нужно сверить; у архивов Binance Vision свои условия — разрешены, например, «потребительские программы» `проверить` |
| **Форекс** | Виджеты (реальное время) | Бесплатного источника **с правом показа пользователям** не нашёл: у Twelve Data бесплатный план только для **внутреннего** использования без показа, показ внешним пользователям — тарифы Business `проверить`. Исторические данные Dukascopy бесплатны для загрузки, но право распространения **не подтверждено** |
| **Индексы** | Виджеты (часть с задержкой) | Нет бесплатного с правом показа; у бирж и провайдеров отдельные лицензии на индексы |
| **Сырьё, металлы** | Виджеты | Как форекс: платно для показа |
| **Облигации, доходности** | Виджеты | Ежедневные доходности казначейства США — официальные публичные данные (кривая доходности) `проверить` |

**Идея, которая снимает вопрос лицензии: «Свои данные».** Человек сам загружает свечи своего брокера (MT5 и другие платформы умеют выгружать историю в CSV). Данные его, видит их только он — как скриншоты в журнале. С ними работают Replay и бэктест по **любому** инструменту без платного провайдера. Импорт CSV у нас уже есть для сделок, мастер можно повторить для свечей.

### 3.2 Платные варианты (на будущее, когда будет доход)

- Twelve Data, Massive (бывший Polygon), Finnhub и другие: цены и права на показ различаются по тарифам; у многих показ внешним пользователям — только в бизнес-тарифах с ценой по запросу.
  - У Finnhub экономический календарь **не входит** в бесплатный план.
  - Все цифры — из сторонних обзоров, `проверить` перед решением.
- Выбирать по трём вещам: право показа пользователям, история минуток для Replay, цена.

### 3.3 Что хранить и кэшировать на сервере

- **Свечи для Replay и бэктеста:** не таблица на каждую свечу (миллионы строк не влезут в бесплатный Supabase), а **файлы по месяцам** в хранилище (`<инструмент>/<таймфрейм>/<год-месяц>`), сжатые. Хранить минутки, старшие таймфреймы собирать из них. Лимиты бесплатного Supabase (база и хранилище) `проверить`.
- **Кэш котировок для карточек** (если не виджеты): одна запись на инструмент, обновление по расписанию; браузер ходит к нам, а не к провайдеру. Ключи провайдера — только в секретах сервера.
- **Календарь и новости** (свои, этап 4): события и заголовки со ссылками, хранить 30–90 дней (число — твоё решение).
- **Свои данные пользователя:** его файлы — в его папке, правила как у скриншотов (RLS, лимит места).
- **Не кэшировать то, что запрещено:** условия FRED API запрещают хранить и кэшировать его содержимое → макро берём напрямую из первоисточников (BLS, BEA, казначейство США и др.), где это разрешено `проверить`.

## 5. Replay и бэктест

### 5.1 Replay

- Выбираешь инструмент, таймфрейм, дату и время (например, «открытие Лондона 12 марта»).
- График показывает историю до этой точки, будущее скрыто.
- Кнопки:
  - шаг на 1 свечу вперёд;
  - проигрывание со скоростью ×1…×10;
  - пауза;
  - прыжок к открытию сессии;
  - смена таймфрейма — старший собирается из минуток, без «подглядывания» вперёд.
- **Тренировочные сделки:** «Купить / Продать» на графике со стопом и целью — **виртуальные**, без денег. Результат считается в R по следующим свечам.
- Каждая тренировочная сделка записывается в **тренировочный журнал**:
  - отдельное пространство с пометкой «тренировка»;
  - **без монет и XP**;
  - не смешивается со статистикой реального журнала;
  - свой дашборд: winrate, средний R, ошибки.
- Работает на любых данных этапа 2: крипта с бирж или «свои данные» пользователя.

### 5.2 Твои правила как проверяемые правила

Каждый шаг — точное определение с настройками. Его видно на графике, поэтому можно проверить, почему правило сработало:

| Шаг | Определение (по умолчанию, настраивается) |
|---|---|
| **Sweep** | Цена проколола последний **swing high/low** (экстремум с N свечами по обе стороны, N = 3) или максимум / минимум прошлой сессии / дня, и свеча **закрылась обратно** за уровнем |
| **Displacement** | Не позже K свечей после sweep — свеча против направления прокола с телом ≥ X × ATR(14) (X = 1,5) |
| **FVG** | Разрыв между свечами 1 и 3 в движении displacement (low свечи 3 > high свечи 1 для роста, и наоборот), не меньше Y × ATR |
| **MSS** | Закрытие за последним противоположным swing-уровнем в сторону displacement, не позже M свечей после sweep |
| **Вход** | Возврат цены в FVG (край / середина — выбор), не позже T свечей; иначе сетап отменяется |
| **Стоп / цель** | Стоп за экстремумом sweep (+ отступ); цель — R-кратное (2R) или противоположная ликвидность |
| **Фильтры** | Сессия (Лондон / Нью-Йорк), дни недели, старший таймфрейм (направление), новости ±30 минут (позже) |

Все числа выше — **черновые настройки по умолчанию для обсуждения**, не утверждены (вопрос 7).

### 5.3 Бэктест

- Движок проходит историю свеча за свечой — так же, как Replay, без подглядывания вперёд — и находит сетапы по правилам.
- Работает **в браузере** в фоновом потоке: серверу не нужно ничего считать, бесплатно.
- **Результат:**
  - список сделок;
  - winrate, средний R, ожидание, максимальная просадка в R;
  - кривая в R;
  - разбивка по сессиям и дням.
- Учёт спреда и комиссии — заглушка, число вводит пользователь.
- **Каждая сделка кликабельна:** открывается Replay в этой точке с разметкой — уровень sweep, свеча displacement, прямоугольник FVG, линия MSS, вход, стоп, цель. Так видно, верно ли сработало правило.
- **Ручной бэктест** = Replay + тренировочный журнал. Классический способ, работает с первого дня этапа 2.
- **Защита от самообмана:**
  - предупреждение о подгонке параметров;
  - разделение периода на «настройку» и «проверку».
- Сохранённые прогоны — у пользователя (позже — в облаке, как журнал).

### 5.4 Связь с Журналом

- **Реальная сделка на графике:** из карточки сделки → «Открыть на графике» → отметки входа и выхода, если есть данные по этому инструменту и времени (крипта или свои данные).
- **Стратегия журнала ↔ правила бэктеста:** у стратегии «Sweep → MSS → FVG» появляется кнопка «Проверить на истории». Чек-лист стратегии остаётся, правила бэктеста — её «точная версия».
- **Тренировочный журнал** — отдельно (см. 5.1). Монеты и XP — нет (твоё решение). Задания за тренировку — только если решишь отдельно.

**Мои идеи (предлагаю, решаешь ты):**
1. **«Сегодня важно» за 2 минуты** (цель Pack 8): одна полоса сверху — какая сессия идёт, ближайшие 3 события высокой важности, инструменты из твоего списка, которые больше всего двигались.
2. **Часы сессий** с подсветкой «killzones» и твоим часовым поясом — без всяких данных, и полезно каждый день.
3. **Связь календаря с журналом:** у сделки, открытой за ±30 минут до важного события, пометка «рядом новость» — помогает в разборе.
4. **Карта корреляций простыми словами** (DXY vs EUR/USD и золото) — позже, на своих данных.
5. **Replay-челлендж:** «найди сетап на этом отрезке» — тренировка без монет и XP. Если захочешь — учебное задание в Академии (D-10).
6. **«Свои данные»** (3.1) — бэктест по любому инструменту без платного провайдера.
